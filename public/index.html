How the engine decides
The browser loads recent Deriv tick history, derives the last digit, and combines frequency, recency weighting, order-2 transition structure, run/streak context and entropy. It then performs a small walk-forward simulation over the same history. If the simulated edge is weak or unstable, the dashboard deliberately returns NO TRADE instead of manufacturing a 96% confidence claim.
